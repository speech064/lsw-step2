# 기억의 갱도 — 제주 서부 일제강점기 진지 다크투어 (2단계)

1단계는 CSV를 파일에 넣어 두고 열었고, 2단계는 **공공데이터포털 API**에서 데이터를 불러와요.
API가 안 될 때는 1단계 파일 데이터로 **연습 모드**로 보여 줘요.

## 실행
1. `.env.local` 에 키 2개를 넣어요 (견본은 `.env.example`).
   - `JEJU_CULTURE_INFO_KEY` : 제주역사문화 일반정보 API 키
   - `JEJU_CULTURE_LOCATION_KEY` : 제주역사문화 위치정보 API 키
2. 터미널에서 이 폴더로 이동해 `node server.js` (또는 `npm start`)
3. 브라우저에서 http://localhost:3000 을 열어요.
   - `index.html` 을 더블클릭해서 열면 API를 부를 수 없어서 **연습 모드**로 열려요(화면은 정상).

키는 코드에 없고, 서버만 환경변수로 읽어요. 브라우저로는 가지 않아요. 제출할 때는 `.env.local` 을 빼요.

## 1. 사이트 구조 (화면 구성)
이 사이트는 **한 페이지(스크롤 1장)** 이고, 위에서 아래로 **5개 화면(구역)** 이 이어져요.

| 번호 | 구역 | 무엇을 보여 주나 |
|---|---|---|
| 1 | 첫 화면 | 제목 "기억의 갱도", 부제, "7곳 · 직선거리 약 30km · 차로 하루". API가 안 되면 "연습 모드" 표시가 여기에 뜸. 오른쪽 위에 글자 크기(A−/A+) |
| 2 | 코스 지도 (ROUTE) | 7곳을 번호 핀과 점선으로 이은 지도, 방문 순서 전환(추천 순서 30.4km / 나열한 순서 41.0km), 거리·시간, 진행률(다녀왔어요 n/7), 내 위치에서 가까운 곳 찾기, 코스 글로 복사, 상태 안내(불러오는 중·연습 모드·경고) |
| 3 | 걸어 들어가는 순서 (STOPS) | 7곳 카드. 장소명·분류·주소·제목·설명, 자료 한계 메모, 다녀왔어요 체크, 내 기억 한 줄, 길찾기·자료 원문 링크. 카드 사이에 구간 거리·이동 시간 |
| 4 | 이 길을 걷기 전에 (BEFORE YOU GO) | 태도·안전·이동 안내 상자 3개 |
| 5 | 출발 전 체크리스트 (CHECKLIST) | 체크할 수 있는 준비 항목 6개 (내 컴퓨터에 저장) |

데이터 흐름: `브라우저 → /api/places → server.js → 공공데이터포털 API 2개(일반정보·위치정보)`. 두 결과를 고유번호로 합쳐서 내려줘요.

## 2. 사용자 관점 개선점 10가지
기준: 다크투어리즘 사이트가 방문자에게 도움이 되려면 무엇이 필요한가. 비교 대상은 아우슈비츠-비르케나우 추모관·박물관 사이트([auschwitz.org](https://www.auschwitz.org))예요. 직접 열어 보니 방문 안내(Visiting)에 기본 정보, 개별 방문자, 방문 계획, 개방 시간, 오시는 길, 온라인 가이드 투어, 방문 준비 자료(Multibook)와 소개 영상, 임시 폐쇄 공지가 있었고, 상단에 예약, 검색, 언어 전환이 있었어요.

| # | 개선점 | 이유 (사용자 관점) | 이번에 한 것 |
|---|---|---|---|
| 1 | 장소별 기본 정보(개방 시간, 주차, 소요 시간, 출입 가능 여부) | 가서 닫혀 있으면 하루가 헛돼요. 아우슈비츠는 개방 시간·오는 길·방문 계획을 따로 둠 | 못 함 (API에 없는 정보. 체크리스트에 "확인하기"로 안내) |
| 2 | 임시 폐쇄·출입 제한 공지 | 동굴·진지는 안전 때문에 막힐 수 있어요. 아우슈비츠는 "임시 폐쇄" 건물을 따로 표시함 | 못 함 (공지 데이터 없음) |
| 3 | 오는 길과 구간 이동 시간 | 하루 코스라 구간마다 얼마나 걸리는지가 중요 | **했음** — 카드 사이에 "거리 · 차로 약 N분", 길찾기 링크 |
| 4 | 방문 전 준비 자료 | 아우슈비츠는 방문 준비 자료와 소개 영상을 제공. 배경을 모르고 가면 의미가 줄어요 | **했음** — "출발 전 체크리스트" 6개 (배경 읽기, 장비, 시간 등) |
| 5 | 해설·가이드(오디오·온라인 가이드) | 안내판이 없는 곳이 많아 혼자 이해하기 어려워요 | 못 함 (콘텐츠가 필요) |
| 6 | 다국어(영어 등) | 아우슈비츠는 여러 언어로 제공. 외국인 방문자도 있어요 | 못 함 (번역이 필요) |
| 7 | 접근성(글자 크기, 대비, 이동 난이도) | 어르신·저시력 방문자, 오름·동굴의 보행 난이도 | **일부** — 글자 크기 90~130% 조절 (난이도 표시는 못 함) |
| 8 | 나의 진행과 기록 | 걷고 나서 기억을 남기는 것이 다크투어의 핵심에 가까워요 | **했음** — "다녀왔어요" 체크(진행률·지도 배지), 장소별 "내 기억 한 줄" |
| 9 | 내 위치에서 가까운 곳 | 현장에서 "지금 어디부터 가지?"를 바로 알 수 있어요 | **했음** — 내 위치 → 가장 가까운 곳, 지도에 내 위치 표시 |
| 10 | 코스 저장·공유와 출처의 정직함 | 일행에게 코스를 보내고, 자료의 한계(공통 설명, 장소 불일치)를 알아야 오해가 없어요 | **했음** — "코스 글로 복사"(체크·메모 포함), 장소별 "메모"(자료 한계), 연습 모드 표시 |

## 3. API 대비
- **불러오는 중**: 지도 위와 카드 목록에 "불러오는 중…" 표시(회전 표시 포함). 데이터가 오면 사라져요.
- **실패하면**: 1단계 파일 데이터(CSV에서 뽑은 7곳, `index.html` 안에 내장)로 화면을 그리고, 첫 화면에 **연습 모드** 배지와 위쪽 안내 칸에 이유를 보여 줘요. "다시 불러오기" 버튼으로 재시도해요.
- 실패 원인별 안내: 서버 꺼짐, 키 비어 있음, 키 오류·활용신청 미승인, 네트워크 오류, 잘못된 응답.
- 위치정보 키만 없을 때는 연습 모드가 아니라 **경고**로 표시하고(주소 대신 좌표) 나머지는 API 데이터로 보여 줘요.
- 확인: `JEJU_CULTURE_INFO_KEY` 를 빈 값으로 둔 서버로 열어 보니 화면이 깨지지 않고 연습 모드로 7곳이 정상 표시됐어요. 서버 없이(API 주소가 404) 열어도 같았어요.

## 4. 고친 것과 추가한 것
**고친 것**
- 데이터 읽기: 파일에 박아 둔 데이터 → API(`/api/places`).
- 글자 크기를 `rem` 기준으로 바꿔 글자 크기 조절이 본문·카드에 적용되게 함.
- 지도 타일: 키가 필요한 CARTO → 키가 필요 없는 Esri(실패 시 OpenStreetMap).
- 두 API를 고유번호로 합쳐 주소·원문 링크를 만듦(`server.js`).
- 지도 번호 스탬프 겹침: 4번(셋알오름)과 5번(섯알오름)은 직선 0.1km라 같은 자리에 찍혀 겹쳤어요. 38px 안에 모인 스탬프는 둘레로 흩어 놓고 실제 위치와 가는 선·작은 점으로 이어요(경로 선은 실제 위치 기준 그대로). 지도를 확대해 서로 멀어지면 제자리로 돌아와요.

**추가한 기능** (모두 실제로 눌러서 동작을 확인함)
1. 불러오는 중 표시 / 연습 모드(실패 시 1단계 데이터) / 다시 불러오기
2. 다녀왔어요 체크 + 진행률 막대 + 지도 핀이 ✓로 바뀜
3. 장소별 "내 기억 한 줄" 메모 (이 컴퓨터의 브라우저에 저장)
4. 글자 크기 조절 (90 / 100 / 115 / 130%)
5. 내 위치에서 가장 가까운 곳 찾기 (위치 허용 필요, 지도에 내 위치 표시)
6. 코스 글로 복사 (순서·주소·다녀옴·메모 포함)
7. 구간별 이동 시간 표시
8. 출발 전 체크리스트 6개 (저장됨)

**확인하지 못한 것**
- 위치 기능은 실제 GPS가 아니라 가짜 위치를 넣어 동작만 확인했어요.
- 모바일 실기기에서는 열어 보지 못했어요.
